# もじババぬき

LINE bot から叩く Webhook 用の Google Apps Script。
送信されたひらがなから 2 個ペアになる文字を取り除き、残りを返します（ひらがなでババ抜き）。

## 仕様

- 受け付けるのはひらがな（ぁ〜ゖ）と長音「ー」のみ
- スペース（半角・全角）・タブ・改行は無視
- それ以外の文字があれば `エラー: ひらがなで入力してください` を返す
- 拗音・促音・濁音・半濁音はすべて別の文字として扱う
- 各文字は 2 個単位で取り除き、奇数個の文字は最初に出現した位置に 1 個残す
- 残った文字は出現順に、スペース・改行なしで返す
- 全てペアで消えた場合は `(のこりなし)` と返信（LINE は空メッセージを送れないため）

例: `じぬし / かじき / かかし` → `ぬかき`

## セットアップ

1. Apps Script プロジェクトを作成し、`Code.gs` の内容を貼り付ける
2. プロジェクトの設定 → スクリプトプロパティに `LINE_CHANNEL_ACCESS_TOKEN` を追加
3. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「全員」
4. 発行された URL を LINE Developers の Webhook URL に設定し、Webhook の利用をオンにする

## テスト

```
node test/babanuki.test.js
```
